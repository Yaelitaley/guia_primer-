🌐 Tema 1: Introducción al Desarrollo Empresarial Web

Un proyecto web profesional consiste en planificar, diseñar, desarrollar y hacer crecer un sitio web para cumplir objetivos empresariales.

Tipos de sitios web

  • Web Corporativa
  • E-Commerce
  • Landing Page
  • Aplicación Web
  • Catálogo o Portal

Fases del desarrollo web

  1. Planificación
  2. Diseño UX/UI
  3. Desarrollo
  4. SEO y contenido
  5. Pruebas
  6. Lanzamiento

🏢 Tema 2: Identificación de la Empresa

Permisos

  • Legales
  • Fiscales
  • Laborales
  • Municipales

Tipos de Empresa

  • Sociedad Anónima (S.A.)
  • Sociedad de Responsabilidad Limitada (S. de R.L.)
  • Persona Física con Actividad Empresarial

FODA

Fortalezas, Oportunidades, Debilidades y Amenazas.

👥 Tema 3: Análisis del Personal

  • Equipos: 55% - 65%
  • Mano de obra: 15% - 25%
  • Ingeniería: 5% - 10%
  • Logística: 5% - 10%
  • Administración: 5% - 10%
CPM = Costo del Personal Mensual Ejemplo: $80,000 ÷ 4 meses = $20,000
BAC = Presupuesto total aprobado del proyecto.

📅 Tema 4: Cronogramas

Cronograma: herramienta que organiza actividades y tiempos de un proyecto.

Tipos

  • Diagrama de Gantt
  • CPM (Ruta Crítica)
  • PERT
